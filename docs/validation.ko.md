## 3. 6DOF 개발 과정 중 해결한 핵심 물리·제어 과제

1. **상승 3D 횡풍 웨더콕 폭주 억제**: 3D Y축 상승 유도에서 상대풍 각도 추종 대신 Day-of-Launch 횡풍 킥 바이어스 + 관성 속도 중심화(`flow_inert_y → 0`) + 원형 3D `q·α` 클램프를 적용해 횡풍 시에도 1-2단 분리 게이트를 정밀 통과했습니다.
2. **2-DOF 구형 진자 슬로시 무중력 적분 발산 해결**: 단순 각도 클램프(`0.48π`) 시 무중력 코스트 구간에서 발생하던 다중 미터 적분 와인드업과 재진입 점화 충격(`3.1~8.1 deg/s²`)을 $2\pi$-주기 구형 포텐셜 + 심플렉틱 중점 적분으로 근본 해소했습니다.
3. **운전점 4-핀 유한차분 선형화 및 3축 외란 토크 바이어스 관측기**: 단순 해석 핀 모델이 놓치던 `-32 kN·m` 핀 항력 웨더콕 모멘트를 운전점 유한차분으로 반영하고, 15-State MEKF의 공력 구간 3축 외란 토크 관측기를 활성화해 예보 오차 및 돌풍에서도 각가속도를 `≤ 4.58 deg/s²`로 억제했습니다.
4. **3D Stage B 공력 짐벌 트림 분리 & 글라이드 AoA 확보**: 1기 착륙 연소 중 `4.5~5.5°` TVC 공력 트림이 본체 자세 목표와 중첩되며 발생하던 오버슈트(`-4.6~-8.3 m`)를 본체 목표에서 정확히 분리하고, 3D X/Y 공유 받음각 한계를 보정해 최종 `edge-3d` 32/32 및 미관측 `holdout-3d` 64/64를 **전원 0.135 m 이내**로 수렴시켰습니다.

## 4. Kaggle 클라우드 재현 명령

```bash
# 4개 Kaggle 무료 CPU 샤드(총 16 vCPU, 0 GPU 쿼터)로 검증 투입
python scripts/kaggle/push_kaggle_shards.py --suite edge-3d --shards 4
python scripts/kaggle/push_kaggle_shards.py --suite holdout-3d --shards 4

# 완료 후 결과 및 동결 50 Hz 3D 리플레이 수집·병합
python scripts/kaggle/collect_kaggle_results.py --suite edge-3d --shards 4
python scripts/kaggle/collect_kaggle_results.py --suite holdout-3d --shards 4
```
